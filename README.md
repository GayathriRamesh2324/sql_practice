# SQL Practice

This repository contains my SQL practice queries organized by topic.
It covers basic to advanced SQL concepts commonly asked in interviews.

## Topics Covered

### 1. String Functions
📁 `String_functions/`

- `string_functions.sql`  
  Contains queries using:
  - LENGTH
  - UPPER / LOWER
  - SUBSTRING
  - CONCAT
  - TRIM
  - Other string manipulation functions

### 2. Joins
📄 `joins.sql`

- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL JOIN
- Join-based interview questions

### 3. Subqueries & Window Functions
📄 `subqueries&windows.sql`

- Subqueries
- Correlated subqueries
- Window functions
- Ranking functions:
  - ROW_NUMBER
  - RANK
  - DENSE_RANK

### 4. Advanced Queries
📄 `advanced_queries.sql`

- CTEs (WITH clause)
- Advanced filtering
- Real-world SQL interview problems

## Purpose

- Practice SQL concepts
- Prepare for SQL interviews
- Maintain a structured SQL reference

## Database Used
- Generic SQL (MySQL / PostgreSQL compatible)
- Table examples like `Employee`, `Department`
